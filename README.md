# Restaurant Website

[View the Project]([https://github.com/IshitaSingh-28/restaurant](https://ishitasingh-28.github.io/restaurant/))

## Description

The Restaurant Website is a fully responsive web application designed to provide a modern user interface and user experience for restaurant-related services. Built using ReactJS, this project aims to offer an intuitive and visually appealing platform for users to explore restaurant menus and place orders.

## Features

- **Responsive Design**: Optimized for various devices to ensure a consistent and seamless user experience across desktops, tablets, and smartphones.
- **Modern UI/UX**: Clean and engaging user interface designed with the latest web design principles.
- **Menu Display**: Showcase restaurant menus with detailed descriptions and pricing.

## Technologies Used

- **ReactJS**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **Framer Motion**: A library for creating smooth animations and interactions.
